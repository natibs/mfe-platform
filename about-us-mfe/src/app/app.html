About Us

This platform is built as a set of independently deployed Angular microfrontends, orchestrated by a shell application using Native Federation. Each page you navigate to — Articles, Contact Us, and this one — is its own Angular app, built and served on its own, and composed together at runtime.

The shell owns routing and layout; the sidebar and footer are themselves microfrontends shared across every page; and everything shares one UI component library and one authentication service so the whole experience feels like a single application.
